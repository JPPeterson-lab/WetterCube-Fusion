# Changelog

*[Deutsche Version](CHANGELOG.md)*

## v0.9.9-beta3 (2026-10-22)

### Changed
- **Source credits:** The notes on data sources now follow Open-Meteo's guidelines and the notes of the German Weather Service. The line "Quelle: Deutscher Wetterdienst" appears on the screens that show DWD data (main screen, allergens, bio-weather, warning map). Open-Meteo, the Copernicus data (CAMS) and the location search via GeoNames are named in the menu under "Datenquellen" and on the settings page, each with the licence (CC BY 4.0) and a note that values are converted. The start screen reads "Weather data by Open-Meteo.com".
- **Interface:** The notes are now elements of the interface instead of being created in code, so they can be moved there. The interface was also revised (new export from PicoPixel).
