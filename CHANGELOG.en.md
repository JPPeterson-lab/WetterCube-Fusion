# Changelog

*[Deutsche Version](CHANGELOG.md)*

## v0.9.9-beta12 (2026-10-23)

### New
- **Second location:** In the web interface (Weather & data) you can enter a second place with its own pollen region and biometeorology zone, for example home and holiday home. A small pill with the place name and two dots then appears at the top left of the main screen. Tapping it switches between the places; weather, 7-day forecast, pollen, warnings, warning map and biometeorology follow the selected place. You can also switch in the web interface. Sensors and history stay with the first location, and after a restart the first location is active again. The second location is part of the settings backup.
- **Screenshot:** In the web interface (Settings, Diagnostics) the button "Save screenshot" saves a PNG of what the display is showing right now.

### Improved
- The screenshot retries up to four times when memory is tight.
