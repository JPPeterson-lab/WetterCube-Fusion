## v1.0.0-rc4 (2026-10-28)

### New
- **Allergy diary:** new page between allergens and warning map. Three buttons ("Keine / Leichte / Starke Beschwerden", none / mild / strong symptoms) record today, 30 bars show the last days, plus the pollen load of your selected allergens as a blue line. Entries are stored on the memory card (`tagebuch.csv`; without a card they stay in memory until restart). The page can be switched off in the web interface (tab Anzeige). In the web interface at `/tagebuch` (tab "Tagebuch") you can view, add, delete and download them as CSV.
